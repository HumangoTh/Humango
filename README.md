# HUMANgo

เว็บไซต์ HUMANgo — https://humango.co

## โครงสร้างไฟล์

```
/                       หน้าเว็บทั้งหมด (.html) อยู่ที่ root เพื่อให้ลิงก์เดิมใช้ได้
├── assets/css/         style.css (CSS ทั้งเว็บ)
├── assets/js/          quiz.js (เอนจินแบบวัด)
├── assets/img/         โลโก้ รูปปกบทความ (cover-*.jpg) รูปแชร์ (og-home.jpg)
├── CNAME               โดเมน humango.co
├── sitemap.xml · robots.txt
```

- รูปปกบทความใหม่: วางไว้ใน `assets/img/` ตั้งชื่อตามที่ระบุใน `assets/css/style.css`
- `assessment-free.html` และ `assessment-growth-mindset.html` = หน้าเก่า ส่งต่อไป `assess-growth-mindset.html`
